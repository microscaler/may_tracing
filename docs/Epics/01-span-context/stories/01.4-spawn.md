# Story 01.4: Spawn with inherited or detached context

## Description

The equivalent of Tokio's `in_current_span()`: a child coroutine spawned through this crate
starts with the spawner's current span (a clone taken on the spawner's side, set as the
child's first action), or explicitly with none. Inheritance is opt-in at the spawn site so
coroutines that do not trace pay nothing and so that "why is this span an orphan" has a
one-line answer: it was spawned with `may::coroutine::spawn` directly, or with
`spawn_detached`.

## Functional Requirements

- [ ] `pub use may::coroutine::{Builder, JoinHandle};`
- [ ] `pub unsafe fn spawn_in_current_span<F, T>(b: Builder, f: F) -> io::Result<JoinHandle<T>>`
      where `F: FnOnce() -> T + Send + 'static, T: Send + 'static`: reads `current()` in the
      caller, `b.spawn(move || with_span(parent, f))`
- [ ] `pub unsafe fn spawn_detached<F, T>(b: Builder, f: F) -> io::Result<JoinHandle<T>>`:
      `b.spawn(move || with_none(f))`
- [ ] `pub unsafe fn spawn_with<F, T>(b: Builder, span: Span, f: F) -> io::Result<JoinHandle<T>>`:
      an explicit span (a handler spawning a stream loop under a span it chose)
- [ ] `pub trait BuilderExt` with the three as methods (`spawn_with_context`, `spawn_detached`,
      `spawn_with_span`), implemented for `may::coroutine::Builder`, so call sites read
      `Builder::new().name("orders-stream").stack_size(256 * 1024).spawn_with_context(f)`
- [ ] Convenience without a builder: `pub unsafe fn go_in_current_span<F, T>(f: F) -> JoinHandle<T>`
      mirroring `may::go!` semantics (default stack), for the common case
- [ ] The `unsafe` is may's contract (the closure must not block the OS thread); each
      function's `# Safety` section says exactly that and nothing more

## Non-Functional Requirements

- [ ] The parent span is cloned **before** `spawn` returns — there is no window where the
      child runs without its context, and the spawner's later `set_current` changes do not
      leak into the child
- [ ] `JoinHandle<T>` is may's; no wrapper type (consumers already match on it)
- [ ] Zero overhead for `spawn_detached` beyond a `Span::none()` write

## Acceptance Criteria

1. Inside `with_span(a, …)`, `spawn_in_current_span` → child's `current().id() == a.id()`
2. Same, `spawn_detached` → child's `current().is_none()`
3. `spawn_with(b, …)` → child's `current().id() == b.id()` regardless of the spawner's context
4. Raw `may::coroutine::spawn` from inside `with_span(a, …)` → child's `current().is_none()`
   (documents the opt-in; this test is the contract)
5. The spawner changing its context after spawning does not change the child's
6. The child's context is independent: `set_current` in the child does not affect the spawner

## Tests

```rust
// tests/spawn.rs
use may_tracing::BuilderExt;

#[test]
fn child_inherits_or_not() {
    let _s = tracing::subscriber::set_default(tracing_subscriber::registry());
    let a = tracing::info_span!("a");
    may_tracing::with_span(a.clone(), || {
        let inherited = unsafe { may_tracing::Builder::new().spawn_with_context(|| may_tracing::current().id()) }.unwrap();
        let detached  = unsafe { may_tracing::Builder::new().spawn_detached(|| may_tracing::current().is_none()) }.unwrap();
        let raw       = unsafe { may::coroutine::spawn(|| may_tracing::current().is_none()) };
        assert_eq!(inherited.join().unwrap(), a.id());
        assert!(detached.join().unwrap());
        assert!(raw.join().unwrap());
    });
}
```
