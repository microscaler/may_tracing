# Story 01.1: Project setup & Cargo.toml

## Description

Stand the crate up in the shape of the other microscaler may crates (`may_postgres`,
`may_minihttp`): `Cargo.toml` with the dual licence, a `src/lib.rs` that compiles empty,
`tests/`, `examples/`, CI, and the docs tree that already exists (`docs/ADR`,
`docs/Design.md`, `docs/Epics`). Features are declared now so later stories do not move
dependency lines around: `default = []`, `otel` (01.7), and `scheduler-hooks` reserved for
ADR-0003 (declared, empty, documented as such).

## Functional Requirements

- [ ] `Cargo.toml`: `name = "may_tracing"`, `version = "0.1.0"`, `edition = "2021"`,
      `license = "MIT/Apache-2.0"`, `repository = "https://github.com/microscaler/may_tracing"`,
      `description = "tracing span context for may coroutines - the may equivalent of Tokio's Instrument"`,
      `keywords = ["may", "coroutine", "tracing", "span", "instrument"]`, `categories = ["asynchronous", "development-tools::debugging"]`
- [ ] Dependencies: `may = "0.3"`, `tracing = "0.1"`; optional `tracing-opentelemetry` and
      `opentelemetry` behind `otel`
- [ ] Dev-dependencies: `tracing-subscriber = { version = "0.3", features = ["registry"] }`
- [ ] Features: `default = []`, `otel = ["dep:tracing-opentelemetry", "dep:opentelemetry"]`,
      `scheduler-hooks = []` with a doc comment pointing at ADR-0003
- [ ] `src/lib.rs` with the crate-level doc (the README's first two paragraphs) and
      `#![deny(missing_docs)]`, `#![forbid(unsafe_op_in_unsafe_fn)]`
- [ ] `LICENSE-MIT`, `LICENSE-APACHE` copied from `may_postgres`
- [ ] `.github/workflows/ci.yml`: `cargo fmt --check`, `cargo clippy --all-features -D warnings`,
      `cargo test --all-features` on `ubuntu-latest` and `macos-latest`, `cargo doc --no-deps`
      with `RUSTDOCFLAGS=-D warnings`
- [ ] `.gitignore`: `target/`, `Cargo.lock` is **committed** (a leaf-ish crate consumed as a
      git dependency; matches may_postgres)
- [ ] `rust-toolchain.toml` pinned to the workspace toolchain the consumers use (check
      BRRTRouter's)

## Non-Functional Requirements

- [ ] `cargo build` with no features pulls no OpenTelemetry crates (check `cargo tree`)
- [ ] The crate compiles with `may` from crates.io **and** with the microscaler fork via
      the ancestor `[patch]` config on ms02 — both are exercised by CI (crates.io) and by
      the consumers (fork)
- [ ] No `build.rs`

## Acceptance Criteria

1. `cargo check --all-features` passes on a fresh clone
2. `cargo tree` without features shows only `may`, `tracing` and their transitive deps
3. CI is green on the initial commit
4. `cargo doc --no-deps` renders the crate doc with links to `docs/ADR/ADR-0002…` resolving on GitHub

## Definition of Done

- [ ] `cargo fmt --check`, `cargo clippy --all-features -D warnings`, `cargo test` pass
- [ ] CI workflow runs on push and PR
- [ ] README's "Status" line updated from "No code yet" to "0.1.0 in progress; see Epic 01"
- [ ] Commit message: `chore: crate skeleton, licences, CI (Epic 01.1)`
