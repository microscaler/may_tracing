# Story 01.5: `child_span!` and `event_in_current!`

## Description

The two macros consumers reach for instead of bare `tracing::span!` / `tracing::event!`:
a span parented on the coroutine's current span, and an event attributed to it. They
forward fields as raw token trees so the `tracing` sigils (`%x`, `?x`, `x = ...`,
`Empty`) all work, and they compile to `parent: None` when there is no context so a
consumer with no BRRTRouter above it (a worker, a test) gets a root span, not a compile
error or a panic.

## Functional Requirements

- [ ] `#[macro_export] macro_rules! child_span { ($lvl:expr, $name:expr $(, $($fields:tt)*)?) => … }`
      expanding to a block that reads `$crate::current()` once and calls
      `::tracing::span!(parent: None | parent: &__p, $lvl, $name, fields…)`
- [ ] Level sugar: `trace_span_in_current!`, `debug_span_in_current!`, `info_span_in_current!`,
      `warn_span_in_current!`, `error_span_in_current!` (names chosen to sit next to
      `tracing::info_span!` in a grep and be unmistakably ours)
- [ ] `#[macro_export] macro_rules! event_in_current { ($lvl:expr, $($rest:tt)*) => … }`
      expanding to `::tracing::event!(parent: None | parent: &__p, $lvl, $($rest)*)`
- [ ] Level sugar: `trace_in_current!`, `debug_in_current!`, `info_in_current!`,
      `warn_in_current!`, `error_in_current!`
- [ ] All macros are usable with `$crate::` paths only (no `use tracing` required at the
      call site; `tracing` is re-exported as `may_tracing::tracing` for that purpose)
- [ ] The disabled-context branch performs no `Span::clone` and no field evaluation beyond
      what `tracing`'s own level filtering does

## Non-Functional Requirements

- [ ] Field forms verified by test: `k = v`, `k = %v`, `k = ?v`, `k = tracing::field::Empty`,
      a trailing comma, no fields
- [ ] Macro hygiene: `__p` does not collide with a caller's identifier (use `$crate`-scoped
      helper fn `__parent_or_none()` returning `Option<Span>` to keep the expansion small)
- [ ] `cargo doc` renders each macro with an example; `#[doc(hidden)]` on the helper

## Acceptance Criteria

1. Under `with_span(a, …)`, `child_span!(Level::INFO, "q", x = %1)` produces a span whose
   parent id (as seen by a recording `Layer`) is `a.id()`
2. With no context, the same call produces a span with no parent
3. `info_in_current!(count = 3, "done")` under `with_span(a, …)` produces an event whose
   parent is `a.id()`; with no context, an event with no parent
4. Every field form in the NFR list compiles and records the expected value
5. `may_tracing::info_in_current!("x")` works with no `use` statements at the call site

## Definition of Done

- [ ] A recording `Layer` under `tests/support/` (records `(span id, parent id, name)` and

## Tests

```rust
// tests/macros.rs
use tests_support::Recorder;   // tests/support/mod.rs

#[test]
fn child_span_parents_on_current() {
    let (layer, rec) = Recorder::new();
    let _s = tracing::subscriber::set_default(tracing_subscriber::registry().with(layer));
    let a = tracing::info_span!("a");
    let child = may_tracing::with_span(a.clone(), || {
        may_tracing::child_span!(tracing::Level::INFO, "child", n = 1, s = %"x", d = ?vec![1])
    });
    assert_eq!(rec.parent_of(child.id().unwrap()), a.id());
    let root = may_tracing::child_span!(tracing::Level::INFO, "root");
    assert_eq!(rec.parent_of(root.id().unwrap()), None);
}

#[test]
fn event_in_current_attributes_to_current() {
    let (layer, rec) = Recorder::new();
    let _s = tracing::subscriber::set_default(tracing_subscriber::registry().with(layer));
    let a = tracing::info_span!("a");
    may_tracing::with_span(a.clone(), || may_tracing::info_in_current!(k = 2, "hello"));
    assert_eq!(rec.last_event_parent(), a.id());
}
```
