# Story 01.8: Docs, example, release 0.1.0

## Description

Make the crate consumable and self-explaining: a README that shows the three calls a
consumer needs, an example that runs, rustdoc that matches, the Design updated to the
shipped shape, and a `v0.1.0` tag that BRRTRouter and lifeguard pin (Epic 02).

## Functional Requirements

- [ ] `README.md`: keep the "why" (already written); add a **Usage** section with the
      request-span shape (set → spawn-with-context → child_span → event), a **Rules**
      section quoting ADR-0001's four points, and a **Feature flags** table
- [ ] `examples/request_context.rs`: a `may` "server" coroutine that sets a request span,
      spawns a "handler" with context, which spawns a "background" coroutine detached; each
      level emits `child_span!` + `info_in_current!`; the example installs a
      `tracing_subscriber::fmt` layer with `with_span_events` so the parent linkage is
      visible in the output; `cargo run --example request_context` shows the tree
- [ ] `examples/otel_propagation.rs` (feature `otel`): two coroutines exchanging a carrier
- [ ] Crate-level rustdoc: the layer table from the README and a link to each ADR
- [ ] `docs/Design.md`: a "Delivered" note per section where the build diverged
      (`spawn_with` from 01.4, the helper fn from 01.5, the reproduction numbers from 01.6)
- [ ] `CHANGELOG.md` (Keep a Changelog), `0.1.0` entry
- [ ] Tag `v0.1.0`; GitHub release notes = the changelog entry

## Non-Functional Requirements

- [ ] `cargo doc --no-deps` with `RUSTDOCFLAGS="-D warnings"` clean, all-features and none
- [ ] Every `pub` item has an example or a link to one
- [ ] README code blocks are doctested (`#![doc = include_str!("../README.md")]` in `lib.rs`)

## Acceptance Criteria

1. A fresh clone: `cargo run --example request_context` prints a span tree with the
   handler and its child under the request, and the detached background span at the root
2. `cargo doc` renders the README as the crate front page with no broken links
3. `may_tracing = { git = "https://github.com/microscaler/may_tracing.git", tag = "v0.1.0" }`
   resolves from a scratch crate on ms02 (and via the ancestor `[patch]` when the sibling
   checkout is present)
4. The Epic 01 README's story table shows every story DONE and the epic DoD ticked

## Definition of Done

- [ ] All of the above; CI green on the tag
- [ ] `docs/Epics/01-span-context/README.md` status → DONE with the date
- [ ] Commit message: `docs: usage, examples, changelog; release 0.1.0 (Epic 01.8)`

## Tests

- The README doctests (via `include_str!`).
- `examples/` are built by CI (`cargo build --examples --all-features`).

## Dependencies
