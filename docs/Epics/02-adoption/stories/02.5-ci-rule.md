# Story 02.5: The ADR-0001 grep in every may crate's CI

**Repos:** BRRTRouter, lifeguard, may_minihttp, PriceWhisperer (`microservices/`)

## Description

ADR-0001's enforcement: a script that fails CI when may code enters a span without an
allow-list note, or creates a span/event without an explicit parent. It lives here
(`scripts/check-span-discipline.sh`) so all four repos run the same rule, and each repo
calls it from its CI with its own paths.

## Functional Requirements

- [ ] `scripts/check-span-discipline.sh <path>…`:
  - fails on any line matching `\.enter\(\)|\.entered\(\)|\.in_scope\(` unless the same
    line or the line above contains `// no-yield:`
  - fails on any `tracing::(span|info_span|debug_span|warn_span|error_span|trace_span)!\(`
    or `tracing::(event|info|warn|error|debug|trace)!\(` that does not contain `parent:`
    unless the line above contains `// root-span:` or `// root-event:`
  - ignores `tests/`, `examples/`, `benches/`, and lines matching `may_tracing::` (the
    macros are the sanctioned form)
  - prints file:line for each hit and a one-line pointer to ADR-0001
- [ ] A `--fix-hint` mode that prints the `child_span!` / `info_in_current!` rewrite for
      each hit (text only; no edits)
- [ ] Wired into: may_tracing's own CI (on `src/`), BRRTRouter (`src/`), lifeguard (`src/`),
      PriceWhisperer (`microservices/` excluding `ingestors/` and `pact-mock-server/`,
      which are Tokio)
- [ ] Each repo's initial run produces an allow-list PR: every remaining `enter` gets a
      `// no-yield:` justification or is converted

## Non-Functional Requirements

- [ ] POSIX sh + grep, no ripgrep dependency (CI images vary); < 1 s on PriceWhisperer
- [ ] Zero false positives on the four repos after the allow-list PRs (each hit is either
      a real violation or annotated)

## Acceptance Criteria

1. Running the script on may_tracing `src/` reports nothing
2. Running it on BRRTRouter after 02.1 reports only the annotated security spans
3. Running it on lifeguard after 02.2 reports nothing
4. Running it on PriceWhisperer `microservices/` after 02.3–02.4 reports nothing
5. Introducing `let _e = span.enter();` in a PR to any of the four fails that PR's CI

## Definition of Done

- [ ] Script + tests (`tests/check_span_discipline.sh` with fixture files that must pass
      and must fail) in may_tracing
- [ ] Four CI wirings merged
- [ ] ADR-0001 "Enforcement" line updated to point at the script
- [ ] Commit message: `ci: ADR-0001 span-discipline check (Epic 02.5)`

## Tests

- Fixture directory with `good.rs` (may_tracing macros, annotated no-yield enter) and
  `bad.rs` (bare enter, bare span!); the test asserts exit codes 0 and 1.

## Dependencies

- 02.1–02.4 for the repos to be clean; the script itself has none

## Notes

- A proper `dylint`/clippy lint would be nicer; the grep is enough to stop the habit and
  costs an afternoon.
